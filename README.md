# Cpark97 Tap

## How do I install these formulae?

`brew install cpark97/tap/<formula>`

Or `brew tap cpark97/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "cpark97/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
